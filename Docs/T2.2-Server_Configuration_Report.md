## Lessons Learnt

### Lesson 1

One of the biggest differences between linux and windows is case
sensitivity- linux incorporates case sensitivity and windows does not.
So throughout this implementation I had to maintain an awareness of case
sensitivity, and at one point, had to reconfigure the DHCP
configurations as I had entered HBpcoint on the reverse file and
hbpcoint on everything else, which when initiated, did not work as
functioned.

### Lesson 2 

Another lesson learnt was the systemctl command, I had no prior
understanding of the systemctl command aside from a few test scripts
ran, and now I have an in depth understanding of how these commands
work.

For instance, systemctl enable will enable any process entered to run
when the system is booted, aka on boot time.
